**Slice 2: export bundle and safe reader** (task 2 partly), `replay/bundle.py`, pure (no database, nothing extracted to disk):
- `build_bundle` writes a deterministic ZIP (fixed member order, timestamps and permissions): `manifest.json`, `events.ndjson`, `calls.ndjson` (stored outcomes), `evaluations.json`, `snapshots.json`, `receipts.json` and a checksum `index.json` (format and bundle version, canonicalization version, manifest hash, event count and chain head, SHA-256 and size per member). The bundle id is the SHA-256 of the archive bytes; `write_bundle` publishes `<sha256>.acbundle` by temp file, fsync and rename, idempotently. Identical evidence gives identical bytes; a broken event chain is refused at export.
- `read_bundle` refuses, with stable `BUNDLE_*` codes: archives or members over the size caps (32 MiB archive, 16 MiB member, 48 MiB total, members read with a bound so a lying header cannot expand), non-flat or traversing names (`../`, absolute, drive, backslash, hidden), symlink, directory, encrypted and non-deflate members, duplicate and unknown files (so no `.py`, `.so`, `.pkl`), missing required files, checksum or file-set mismatch against the index, unsupported format, bundle or canonicalization version, malformed or non-finite JSON, unknown event types, duplicate call ids, a manifest whose hash differs from the recorded one, and an event stream whose recomputed hash chain, count or head disagree (so rewriting an event and its checksum index together is still caught). Symlink, traversal and decompression-bomb inputs are tested; JSON only, no pickle or object loading, nothing is imported or executed.
- Results: 43 unit tests (`test_bundle.py`; every single-byte corruption of a real archive is either refused with a `BundleError` or yields a different bundle id); 7 new integration tests in `test_replay.py` (36 total, passed in one file run, 105 s): five fixtures (naive and resilient, healthy, 429, timeout-after, CAS conflict, document injection) are exported, **the PostgreSQL data tables are truncated**, and the bundle is read and strictly replayed under the same dispatcher, gateway and socket tripwires (every item consumed); a bundle whose manifest says `partial` capture is readable for playback but strict replay is refused (`REPLAY_CAPABILITY_PARTIAL`); a budget-stopped attempt exports for playback but is `NotReplayable`.

- Verification run: `agentcrash check` passed (ruff, mypy strict on 102 files, schemas up to date); 355 non-DB tests passed, 1 skipped (`test_a_path_must_be_a_regular_file...`: creating a symlink to a bundle needs a privilege this Windows account lacks; the in-archive symlink case ran and passed; CI on Linux will exercise the skipped one). All M1 tasks from IMPLEMENTATION.md are implemented, except generating the typed web client, which is M6's task (D-024). Nothing executes an agent: accepted runs stay `queued` until the M2 worker exists.

**Implemented** (`src/agentcrash/`):
- Domain: `domain/canonical.py` (acl-c14n-v1 hashing), `models.py` (strict models, 8-way fault-effect union), `diagnostics.py`, `registry.py`, `ports.py` (Store port + read models), `pagination.py` (opaque keyset cursors).
- Scenarios: `loader.py` (hostile-input-safe YAML *and* JSON), `compiler.py` (registry resolution, ambiguity rejection, normalization, hashing), `manifest.py` (run validation, immutable manifest).
- Storage: `storage/schema.py` (Core tables), `store.py` (`PostgresStore`), `engine.py`; `migrations/versions/0001_initial_schema.py` (hand-written DDL; scenario immutability trigger; one-active-execute-job partial unique index; restrictive FKs); `alembic.ini`, `migrations/env.py`.
- API (`api/`): bearer auth (constant-time), error envelope with server-generated `X-Request-ID`, `GET /health/live|ready`, `GET /api/v1/agents`, `POST|GET /api/v1/scenarios`, `GET /api/v1/scenarios/{id}/versions/{v}`, `POST|GET /api/v1/runs`, `GET /api/v1/runs/{id}`; idempotency, queue cap 100, in-process 10/min rate limit, 1 MiB streamed body cap, keyset pagination. The API imports only `domain` and `scenarios`; the store is injected by `bootstrap.py`.
- CLI: `agentcrash dev init` (token created once, never overwritten; idempotent seeding; refuses an unmigrated database), `agentcrash api` (real app factory), `scenarios validate`, `check` (now also OpenAPI/schema drift).
- Generated: `schemas/domain.schema.json`, `schemas/openapi.json` (drift-checked in `agentcrash check`).
